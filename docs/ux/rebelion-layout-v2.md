# Rebelion — Layout V2

## Objetivo

Fazer o Rebelion parecer menos genérico e mais próximo da proposta de produto: um hub de presença, espaços, DMs e identidade.

## Nova linguagem de navegação

A navegação deixa de parecer apenas uma lista de telas comuns e passa a representar zonas do app:

```txt
Hub       → presença, ações rápidas e pulso social
DMs       → conversas diretas
Espaços   → grupos/comunidades criadas pelo usuário
Radar     → descoberta de pessoas, espaços e comunidades
Eu        → identidade e personalização
```

## Mudanças aplicadas

### Hub

A antiga tela Início virou **Hub**.

O Hub agora possui:

- cabeçalho próprio;
- card de presença;
- grade de criação;
- área de Pulso.

### DMs

A antiga tela Conversas virou **DMs**.

Linguagem aplicada:

- `Iniciar DM`;
- `Nenhum laço iniciado`.

### Espaços

A antiga tela Grupos virou **Espaços**.

Linguagem aplicada:

- `Criar espaço`;
- `Nenhum espaço criado`.

### Radar

A antiga tela Explorar virou **Radar**.

Linguagem aplicada:

- `Nada no radar ainda`;
- descoberta ligada aos interesses do usuário.

### Eu

A antiga tela Perfil virou **Eu**.

Objetivo:

- reforçar identidade;
- preparar personalização;
- tornar o perfil mais pessoal.

## Princípio visual

> O Rebelion não é um feed. É um hub de presença, espaços e conexões.

## Próxima evolução

A próxima etapa recomendada é transformar os botões do Hub em fluxos reais:

- Criar espaço;
- Iniciar DM;
- Gravar voz;
- Personalizar perfil.
