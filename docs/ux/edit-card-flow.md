# Rebelion — fluxo Editar Cartão

## Objetivo

Transformar a aba Eu em uma área de personalização funcional, começando pelo Cartão Rebelion.

## Implementado na primeira versão

A tela `Editar Cartão` permite ajustar, durante a sessão:

- nickname;
- bio;
- status/presença;
- interesses;
- intenção de estilo do cartão.

Ao salvar, o Cartão Rebelion é atualizado na aba Eu.

## Entradas para a tela

A tela pode ser aberta por:

- botão `Editar Cartão` na aba Eu;
- botão `Personalizar` no Hub.
