# Rebelion — estilos visuais do Cartão

## Objetivo

Separar a identidade visual do usuário da interface padrão do app.

A interface global do Rebelion continua neutra, usando o tema Mono. O Cartão Rebelion, porém, pode receber estilos visuais próprios para representar a identidade do usuário.

## Estilos iniciais

### Mono

Estilo padrão, neutro e maduro.

- grafite;
- cinza;
- branco suave.

### Neon

Estilo mais energético.

- fundo escuro;
- azul/ciano;
- sensação digital.

### Aurora

Estilo mais expressivo.

- fundo escuro;
- roxo/rosa;
- sensação criativa.

### Minimal

Estilo limpo e claro.

- preto;
- cinza;
- branco forte.

## Regra de produto

O tema do app e o estilo do cartão são coisas diferentes.

```txt
Tema do app: como o usuário vê a interface.
Estilo do cartão: como o usuário se apresenta para os outros.
```

## Implementado agora

Ao editar o Cartão Rebelion, o usuário pode escolher um estilo. O estilo altera:

- gradiente do banner;
- cor do avatar;
- cor do status;
- borda do cartão;
- selo de estilo no Cartão Rebelion.
