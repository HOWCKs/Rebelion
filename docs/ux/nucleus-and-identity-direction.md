# Rebelion — Núcleo e Cartão Rebelion

## Direção

Para diferenciar o app, o Rebelion passa a usar dois conceitos visuais próprios:

```txt
Núcleo
Cartão Rebelion
```

Esses elementos ajudam o app a fugir do padrão comum de feed, lista de chats e perfil simples.

## Núcleo

O Núcleo vive no Hub.

Ele representa o estado social atual do usuário:

- presença;
- movimento;
- DMs;
- espaços;
- convites;
- sinais importantes.

Estado inicial:

```txt
Núcleo quieto
0 DMs
0 Espaços
0 Convites
```

Quando o app evoluir, o Núcleo pode reagir a eventos reais:

- nova DM;
- convite recebido;
- espaço com atividade;
- solicitação pendente;
- sala de voz ativa;
- núcleo de um espaço atualizado.

## Cartão Rebelion

O Cartão Rebelion vive na aba Eu.

Ele representa a identidade pública do usuário:

- presença;
- bio;
- identidade;
- estilo;
- controle.

A tela Eu deixa de ser somente um perfil comum e passa a ser uma área de identidade e personalização.

## Linguagem principal

```txt
Presença → como o usuário aparece agora.
Núcleo   → centro de movimento e sinais importantes.
Pulso    → atividade social relevante.
Espaços  → lugares criados pelo usuário/comunidade.
Eu       → identidade e controle pessoal.
```
