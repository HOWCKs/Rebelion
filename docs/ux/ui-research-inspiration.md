# Rebelion — pesquisa de referências UI/UX

## Objetivo

Reunir referências de UI/UX para orientar a evolução visual do Rebelion sem copiar diretamente nenhum aplicativo.

## Referências observadas

### Discord Mobile

A reformulação mobile do Discord separou servidores, mensagens, notificações e perfil em abas mais claras, reforçando que apps de comunidade precisam de navegação simples no celular. A atualização também deu mais peso para DMs/mensagens, busca e perfil do usuário.

Referências:

- The Verge: https://www.theverge.com/2023/12/5/23989155/discord-mobile-app-refresh-midnight-view
- Indian Express: https://indianexpress.com/article/technology/tech-news-technology/latest-discord-update-brings-new-ui-makes-search-easier-loads-faster-on-mobile-and-more-9056558/
- Hindustan Times Tech: https://tech.hindustantimes.com/tech/news/discord-mobile-app-update-adds-dedicated-tabs-improves-functionalities-know-how-to-use-them-71701837863740.html

### Empty states

Boas telas vazias não devem ser becos sem saída. Elas precisam explicar o motivo da ausência de conteúdo e sugerir uma ação clara.

Referências:

- Mobbin Empty State: https://mobbin.com/glossary/empty-state
- UXPin Empty States: https://www.uxpin.com/studio/blog/ux-best-practices-designing-the-overlooked-empty-states/
- Setproduct Empty State: https://www.setproduct.com/blog/empty-state-ui-design

### Perfil e identidade

Páginas de perfil geralmente precisam equilibrar avatar, nome, bio, interesses, ações e controles de privacidade. Para o Rebelion, isso deve evoluir para o Cartão Rebelion, com foco em presença, identidade, estilo e controle.

Referências:

- UXPin Profile Page UI: https://www.uxpin.com/studio/blog/profile-page-ui-design/
- Mobbin Avatar UI: https://mobbin.com/glossary/avatar

## Oportunidades para o Rebelion

### 1. Navegação própria

Em vez de usar nomes genéricos como Início, Conversas, Grupos e Perfil, o Rebelion já usa:

```txt
Hub
DMs
Espaços
Radar
Eu
```

Isso diferencia o app e cria linguagem própria.

### 2. Núcleo como centro da experiência

O Núcleo pode ser o elemento mais reconhecível do Rebelion.

Ele pode mostrar:

- DMs;
- espaços;
- convites;
- presença;
- eventos;
- salas de voz;
- núcleos atualizados.

### 3. Cartão Rebelion

O perfil não deve ser só um perfil. Ele deve ser um cartão de identidade social.

Blocos planejados:

- Presença;
- Identidade;
- Estilo;
- Controle.

### 4. Estados vazios como onboarding

Quando não existe conteúdo, o app deve guiar o usuário com uma ação real:

- criar espaço;
- iniciar DM;
- editar cartão;
- escolher interesses;
- entrar por convite.

## Decisão para próximas versões

O Rebelion deve continuar evitando copiar o padrão visual do Discord ou WhatsApp. A interface deve usar as boas práticas pesquisadas, mas traduzidas para os conceitos próprios:

```txt
Presença
Núcleo
Pulso
Espaços
Cartão Rebelion
Radar
```
